Entry for the make.fun bounty **One Word From Your Ex** — send exactly one
word, the word your ex would use to describe you, and nothing else. The
judge picks the funniest, most painfully honest word.

## The word

**Roommate**

By the end of a dead relationship, that is the word exes actually reach
for: "by the end he was just a roommate." One ordinary word, no setup
needed — the romance evaporated and all that was left was someone sharing
the rent, the fridge and the silence. Funny because it is mundane, and it
stings because it is true.

## How it works

`main.ts` (Node 22, stdlib only) validates the word — exactly one token,
letters only, 1–24 characters — then writes it and nothing else to
`/output/entry.txt`. No trailing newline, no punctuation: the gate counts
every character and the judge reads the text exactly as submitted.

Run it:

```
node main.ts
cat /output/entry.txt
```
